# HDP Map Engine Pro - Frontend

React 18 + Vite + Leaflet map application with 18 interactive layers.

## Features
- Interactive Leaflet map with OpenStreetMap base tiles
- 18 toggleable feature layers
- Redux state management
- Real-time API integration
- Responsive design

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
